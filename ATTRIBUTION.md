# Brali attribution

Brali is a living practical-knowledge library and dataset. The root `LICENSE` remains the authoritative legal license for original repository material. This file states the project's requested attribution identity and machine-reuse guidance; it is not a replacement license and is not legal advice.

## Attribution identity

When Brali material is shared, adapted, quoted, embedded, or returned by an AI system under circumstances where attribution is required, preserve a reasonable attribution to:

- **Creator:** Dzmitryi Kharlanau
- **Project:** Brali
- **Canonical source:** the Brali record URL when one exists, otherwise `https://brali-lifeos.github.io/`
- **License:** CC BY-NC-SA 4.0 for original material unless a more specific notice applies

Compact form:

`Brali — Dzmitryi Kharlanau — <canonical Brali URL>`

For research or versioned dataset use, use `CITATION.cff` and pin the `data-v*` release used.

## AI and agent outputs

When an AI agent recommends or summarizes Brali material, it should preserve:

1. the canonical Brali URL;
2. the evidence state supplied by Brali;
3. attribution to `Brali — Dzmitryi Kharlanau` when the interface permits citations or source labels;
4. direct research-source links for reviewed material when Brali supplies them;
5. important limitations or uncertainty metadata.

Do not present `pending-review` or `restricted` material as trusted Brali guidance merely because it is present in a public dataset.

## Adaptations

If Brali material is changed, translated, merged into another dataset, or substantially rewritten, indicate that it was adapted. Do not remove evidence or provenance metadata in a way that makes a weaker record appear more strongly supported.

## Commercial use

Machine readability does not create an additional commercial license grant. Commercial use requires the permissions described in `LICENSING.md` and the root `LICENSE`.
