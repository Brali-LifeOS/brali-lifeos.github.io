A Self-Guided Mobile Mindfulness Intervention Embedded in Daily Routines for Adults With Mild to Moderate Psychological Distress: Randomized Controlled Trial

For Brali's existing short meditation page, a stable daily routine can be offered as an optional cue when the user's main friction is remembering or initiating practice. A 21-day routine-embedded mobile mindfulness format produced broadly comparable short-term outcomes to a traditional session-based mobile mindfulness format in this trial.
