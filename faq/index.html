FAQ

What Brali is becoming.

The project started as a feature-rich personal organizer. Its strongest reusable asset turned out to be the knowledge itself, so the public project is now being built around the library, data quality, and ways for people and machines to use it.

What is Brali today?

Brali is a public practical knowledge library and data source organized into Life Areas, Growth Zones, and individual protocols. The LifeOS app is an optional application layer for turning a protocol into tasks, check-ins, journals, time logs, or personal metrics.

Why call them protocols instead of hacks?

“Hack” is useful shorthand, but it can imply a trick that works universally. A Brali protocol is more precise: a practical thing to try, a small action, something to observe, and a review point. The goal is not to collect more advice. It is to make advice testable.

Are all protocols scientifically proven?

No. That distinction is deliberately visible. Entries can be reviewed, practical, pending-review, or restricted. Evidence-like claims require traceable sources and editorial review. Low-risk practical suggestions can be published without pretending that a study proves them.

How should I use a protocol?

Choose one that matches a real problem, make the first action small, decide what signal you will notice, try it, and review what happened. Keep it, change it, or drop it. The protocol is a starting point, not a commandment handed down from the productivity heavens.

Can AI agents use Brali data?

Yes, subject to the license. Start with For AI & developers and the Trusted Protocol Feed. Brali also exposes evidence and indexing metadata so an agent does not have to treat every record as equally trustworthy.

What is the difference between the full library and the Trusted Protocol Feed?

The full library preserves the broader corpus and provenance. The Trusted Protocol Feed is smaller by design: it contains only entries that currently meet Brali's public discovery bar. This gives agents and external applications a safer default.

Can I use Brali data commercially?

The current public repository license is non-commercial. Commercial products, paid services, commercial AI integrations, or commercial model-training use require a separate written agreement. See Partnerships and the repository licensing guide for the current boundary.

Can I use Brali for research or a non-commercial project?

Yes, if your use follows the repository license, including attribution and share-alike requirements where they apply. Preserve canonical URLs and evidence metadata when possible so downstream users can inspect provenance.

Is Brali available in multiple languages?

English is the canonical published language today. Multilingual publishing is part of the platform direction. New language versions should preserve stable protocol identity, declare language explicitly, and use proper localized URLs and hreflang rather than machine-translating thousands of thin pages just to impress a crawler.

How are corrections and weak claims handled?

Brali keeps an evidence index, an editorial review queue, and a public methodology. Repeated inherited claims can be corrected through documented editorial normalizations instead of silently rewriting history.

Is this medical, mental-health, legal, or financial advice?

No. Brali provides general educational and personal-development material. Sensitive entries have a higher review bar, and restricted material is kept out of normal search discovery until it meets that bar.

Is the mobile app still the main product?

No. The app remains useful as one way to apply the knowledge, but the public project's long-term center is the knowledge layer: protocols, evidence, taxonomy, machine-readable data, localization, research, and integrations.

How can an organization work with Brali?

Possible collaboration areas include commercial data licensing, agent integrations, MCP access, localization, research, editorial review, custom collections, and embedded protocol experiences. See Partnerships.
