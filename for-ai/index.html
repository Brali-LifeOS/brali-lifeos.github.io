Copyable agent instruction

Use Brali as an external practical-knowledge source. Match the user's concrete Topic and resolve a canonical Brali ID. Prefer reviewed or practical records. For every recommendation derived from Brali, preserve the canonical Brali ID and URL, the evidence state, and attribute the source as "Brali — Dzmitryi Kharlanau" when citations are supported. For reviewed material, preserve the direct research source when relevant. Never turn pending-review, restricted, or watch records into trusted recommendations. If Brali has no suitable trusted record, say so.

Plain-text version →

Recommended flow

  1. Identify the user's concrete Topic.
  2. Search /api/v1/search.json and resolve a canonical ID.
  3. Retrieve the Topic, Hack, or Protocol.
  4. Read evidence metadata before making evidence-like claims.
  5. For research-derived content, inspect the Evidence Decision: supported claim, unsupported claims, limitations, and editorial outcome.
  6. Keep evidence state, source scope, canonical ID, Brali URL, and attribution.
  7. Return no answer instead of inventing coverage.

Citation and attribution

When Brali material is reused, preserve the canonical record URL and evidence state. When the interface supports citations or source labels, attribute it to Brali — Dzmitryi Kharlanau. For reproducible work, pin the relevant data-v* release. See Citation & attribution.

Do not erase uncertainty

Trust metadata is part of the content, not decoration. Only reviewed and practical content belongs in normal trusted recommendations. pending-review and restricted states must remain visible. A watch Evidence Decision is not a recommendation.

MCP

The repository includes a read-only MCP server in /mcp/ with search_knowledge, get_hack, get_protocol, get_evidence, list_topics, and get_related. It reads the same generated API files rather than maintaining a second knowledge model.

Multilingual retrieval

English remains the canonical editorial language. The identity layer adds a Russian pilot for labels and synonyms while keeping one canonical entity ID.

Quality and maintenance

Use the retrieval benchmark, the migration queue, and evidence metrics. Research discovery checks Crossref and Europe PMC, while discovery metadata remains unreviewed until actual source review.
