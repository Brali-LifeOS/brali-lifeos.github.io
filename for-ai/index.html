Recommended agent flow

  1. Resolve the user's intent to a Life Area or Growth Zone.
  2. Retrieve candidate records from the Trusted Protocol Feed.
  3. Prefer entries with reviewed or practical evidence states.
  4. Present the concrete action and check-in without upgrading the evidence claim.
  5. Keep the canonical Brali URL for provenance and deeper reading.

Machine-readable entry points

  • Trusted Protocol Feed (JSON) — compact discovery-ready records.
  • Growth Library corpus (JSON) — broader source corpus for research and provenance.
  • Evidence status index — trust state and review metadata.
  • Editorial review queue — material still requiring review.
  • Indexing policy output — which entries meet the public discovery bar.
  • Dataset manifest — catalog-level metadata.
  • llms.txt — concise orientation for language-model tools.

The feed itself declares a schema version and field list. A separate formal integration schema should be published when Brali introduces a versioned API or MCP service, rather than pretending a contract exists before it does.

Language model

English is the canonical published language today. Future translations should preserve stable protocol identity while declaring language explicitly, so an agent can request a language rather than guessing from duplicated text. Brali will add localized routes and hreflang only when real translated content exists.

MCP direction

The static feeds are the current public interface. A future MCP layer can expose search and read operations over the same protocol records without creating a second source of truth. Until that service is published, integrations should use the machine-readable files above.

Licensing and commercial use

The current public material is governed by the repository license. Non-commercial use must follow its attribution and share-alike conditions. Commercial products, paid services, commercial AI integrations, or commercial model-training use require a separate agreement. See Partnerships and the repository's licensing guide.

Do not erase uncertainty

Brali is not a database of universal truths. Protocols are starting points for practice. Agents should preserve evidence states, avoid turning practical suggestions into medical or scientific claims, and point users to qualified help when a topic falls outside general educational guidance.
