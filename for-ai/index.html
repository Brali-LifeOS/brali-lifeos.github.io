A simple agent flow

  1. Find the Life Area or Growth Zone that matches the user's need.
  2. Retrieve a few protocols from the trusted feed.
  3. Prefer reviewed or practical entries.
  4. Show the action, evidence state, and Brali page.
  5. If a reviewed entry has evidence.source_url, keep that link with the answer.

Machine-readable files

  • protocols.json — smaller trusted protocol feed.
  • hacks.json — broader library corpus.
  • evidence.json — evidence and review status.
  • aliases.json — old protocol slugs mapped to canonical protocols.
  • review-queue.json — items that still need review.
  • indexing.json — public discovery status.
  • manifest.json — dataset overview.
  • llms.txt — short project guide for language-model tools.

Aliases and canonical protocols

Brali keeps some older URLs for compatibility. If a record appears in aliases.json, use its canonical_slug and canonical_url instead. Alias pages are not separate recommendations and stay out of the Trusted Protocol Feed and editorial review queue.

Evidence links

A source being present is not the same as a source being reviewed. The trusted feed exposes an external evidence.source_url only when the protocol has reviewed status. Practical entries can still be useful, but they should not borrow the authority of an unreviewed link.

Evidence

Do not turn a practical suggestion into a scientific claim. Keep the evidence state when you show or reuse a protocol. See the methodology.

Languages

English is the main published language today. Future translations will keep the same protocol identity and add language metadata, so different language versions can stay connected.

MCP

The JSON files are the public interface today. A future MCP service can add search and read tools over the same data. Until then, use the files above.

Licensing

Non-commercial use must follow the repository license. Commercial products, paid services, commercial AI use, or model training require a separate agreement. See Partnerships.

Do not erase uncertainty

Brali is a library of things to try, not a database of universal truths. Preserve the evidence state and reviewed source link when possible.
