Use the packet in an AI agent
Copy agent context and give it to the model or agent runtime you already use. The packet instructs downstream systems to preserve evidence state and cite Brali when the material informs an answer. For programmatic use, start with Knowledge API v1, integration kits, or the local MCP setup.
Privacy and limits
Your question is processed in your browser. This page has no account or Brali server-side query log. Public JSON files are downloaded like ordinary website assets. Outcome feedback is opt-in: the event envelope excludes the raw query and user identity, and no feedback leaves the page until you explicitly download, share, or open a GitHub draft. Brali is not a medical service, and safety-sensitive diagnosis/treatment requests are deliberately excluded from normal recommendations.
Attribution
Each result carries a canonical Brali record URL/ID and evidence state. See citation guidance and deterministic reference demos.
