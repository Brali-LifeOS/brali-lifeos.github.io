What this proves

Brali can be consumed without a custom backend. The browser loads public API v1 JSON, routes the question to canonical Topics, filters normal recommendations to reviewed/practical, and preserves provenance instead of generating unsupported prose.

Use the packet in an AI agent

Copy agent context and give it to the model or agent runtime you already use. The packet instructs downstream systems to preserve evidence state and cite Brali when the material informs an answer. For programmatic use, start with Knowledge API v1, integration kits, or the local MCP setup.

Privacy and limits

Your question is processed in your browser. This page has no account, cookie, analytics event, or Brali server-side query log. The public JSON files are downloaded like ordinary website assets. Brali is not a medical service, and safety-sensitive diagnosis/treatment requests are deliberately excluded from normal recommendations.

Attribution

Each result carries a canonical Brali record URL/ID and evidence state. See citation guidance and deterministic reference demos.

Help improve Brali retrieval

If the match is wrong or useful knowledge is missing, open a prefilled GitHub issue draft. The current query and returned IDs are added to the draft only when you click the link; review the draft before submitting it.
