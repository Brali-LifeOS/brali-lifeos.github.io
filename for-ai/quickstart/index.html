AI quickstart

Connect an agent without losing provenance.

Brali exposes the same canonical knowledge through static API v1, versioned data releases, and an optional read-only MCP server. The important part is not fetching JSON. It is keeping identity, evidence, and citation attached.

Problem-first retrieval

  1. Search /api/v1/search.json using the user's words and aliases.
  2. Resolve the canonical Topic or Protocol ID.
  3. Read the canonical item from the API.
  4. Read evidence metadata before making an evidence-like claim.
  5. For research-derived content, inspect the Evidence Decision when available.
  6. Return the canonical Brali URL and attribution with the answer.

MCP

The read-only MCP server lives in /mcp/ and reads the same generated API. Available tools include search_knowledge, get_hack, get_protocol, get_evidence, list_topics, and get_related.

npm run build
cd mcp
npm install
npm start

Reproducible integrations

For research or long-lived systems, pin a data-v* release. Releases contain manifests and SHA-256 checksums. See Citation & attribution and the repository integration guide.
