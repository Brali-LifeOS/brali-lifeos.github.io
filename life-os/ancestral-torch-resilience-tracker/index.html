Short Resilience Reminder

Use one sentence to reconnect with a controllable next step

Protocol summary · practical

Try this

Write one sentence in the form: This is difficult, and the next thing I can control is ___. Keep it specific to the current situation.

Check-in: Did the phrase lead to a concrete action, or did it become empty motivation that you repeated without changing anything?

Evidence: Practical guidance; no evidence-like claim is detected in the current source record.

Review note: Public content is replaced by a short controllable-next-step reminder. Ancestry, resilience-performance and motivational outcome claims are removed; the phrase is kept only if it changes a concrete next action.

A short phrase is useful only when it changes what you do next. Keep the wording believable, specific, and connected to something under your control.

1. Name the difficulty plainly

Avoid forced positivity. State the difficult part in a few words so the reminder does not require pretending.

2. Name what remains controllable

Choose one controllable behavior such as send the message, ask for help, reduce the scope, prepare the document, or rest before continuing.

3. Write one line

Keep the reminder short enough to remember. Its job is orientation, not inspiration.

4. Discard it if it becomes empty

If the phrase no longer changes attention or action, rewrite it or stop using it.

Questions to consider

Should the phrase sound positive?

Not necessarily. It should sound believable. A useful reminder can acknowledge that something is difficult while still pointing to a workable next step.

Can I reuse the same phrase?

Yes, if it still directs attention toward a real action. Rewrite it when it becomes background noise.

Try it, then review.

Use the action above as a starting point. Adapt it to your situation, notice what happens, and keep, change, or drop it.
