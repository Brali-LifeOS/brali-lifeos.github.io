Judge Each Option Against the Same Criteria

Spot the Contrast Trap

Protocol summary · practical

Try this

State the outcome and non-negotiables. Review each option separately using the same short criteria and note pass, unclear or fail. Compare only after the separate assessments are complete. Recheck any choice that depends mainly on the previous option looking unusually good or bad.

Check-in: Would I make the same choice if this option appeared first, and which criterion actually supports the decision?

An option can look better or worse because of what appeared immediately before it. A stable decision process starts with the outcome and criteria, not with the order in which options happened to arrive.

1. Define the outcome

Write what the decision must accomplish and which constraints cannot be traded away. This becomes the standard against which every option is judged.

2. Use the same criteria for every option

Keep the list short and observable: required capability, total cost, implementation effort, reliability, timing or another decision-specific condition.

3. Assess each option separately

Review one option without discussing whether it is better than the previous one. Mark each criterion as pass, unclear or fail and note what information is missing.

4. Compare after separate assessment

Now compare the completed notes. Resolve trade-offs using the stated outcome rather than letting an extreme option define what counts as acceptable.

5. Run an order check

Ask whether the choice would remain the same if the options appeared in another order or without a deliberately weak or expensive comparison. Reassess when the answer is unclear.

Questions to consider

Should I avoid comparing options?

No. Comparison is necessary. The protocol delays comparison until each option has been judged against a stable standard.

Do I need a numeric score?

No. Short labels such as pass, unclear and fail are enough when they refer to the same criteria. Numbers can create false precision when the criteria are vague.

What if the decision must be fast?

Use one non-negotiable criterion and ask whether the option meets it without reference to the preceding option. Record the larger review for decisions that can wait.

Try it, then review.

Use the action above as a starting point. Adapt it to your situation, notice what happens, and keep, change, or drop it.
