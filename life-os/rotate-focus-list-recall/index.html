Overcome Memory Inhibition

Protocol summary · practical

Try this

To retrieve all items: - Rotate focus: Review all parts of a list instead of sticking to the first items. - Use triggers: Write down clues to jog your memory for the forgotten parts. - Repeat evenly: Go over the list multiple times without overemphasizing certain items. Example: When revising notes, review sections evenly instead of just re-reading the first few pages.

Check-in: Check in when you recover forgotten parts of a list by balancing your focus.
