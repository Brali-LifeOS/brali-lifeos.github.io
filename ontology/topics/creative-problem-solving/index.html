Creative Problem Solving

Combine reframing, constraints, analogy, and experimentation to solve problems differently.

Status: growth-gap. 6 current library entries map here through legacy or reviewed record-level classification.

  • Explain One Idea with an Analogy and Its LimitCompare an unfamiliar idea with something familiar, state the matching point, name where the comparison stops and ask the listener to restate the idea.
  • Translate a Problem into a Nature-Inspired Design PrincipleDescribe the function a solution must perform, inspect a biological example, extract a transferable principle and test one safe application without copying the organism literally.
  • Use an Extreme Seed, Then Return to RealityStart an idea session with a deliberately unrealistic seed, explore its consequences without defending it and then translate useful fragments back into real constraints.
