Contribute without a partnership

You do not need a partnership to improve the public library. You can propose your own practice, protocol, or a problem Brali should cover. Use the structured GitHub forms so each contribution enters the right review path.

  • Propose your own knowledge or protocol.
  • Suggest a source for evidence screening.
  • Report a content or data correction.
  • Propose a taxonomy change.

One boundary across every path

Machine-readable access does not erase evidence state, source provenance, canonical identity, or licensing terms. Partnership proposals should explain how those fields remain visible to downstream users.
