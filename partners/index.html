Review rules

Evidence-like submissions need a traceable source and claim scope. A source suggestion does not change an evidence state by itself. See the contribution, source, and content-quality policies before proposing an evidence change.

Commercial dataset licensing

The public repository license is non-commercial. Paid products, commercial AI use, redistribution and custom commercial delivery require a separate agreement.

AI and agent integrations

Use the versioned API or MCP layer while preserving evidence state and canonical identity.

Technical starting point

Integrators should begin with For AI & developers and API v1. Research users should pin a versioned data-v* release.
