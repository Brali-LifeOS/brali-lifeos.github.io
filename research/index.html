What belongs here

Research notes are not another pile of long articles. Each note should answer a useful question and explain what it changes in Brali.

  • Evidence notes: check an idea against research and explain what the sources do and do not support.
  • Trend notes: watch useful developments in behavior change, learning, wellbeing, productivity, and AI-assisted tools.
  • Open questions: record questions that could improve the library, recommendations, evidence model, or translations.

How we write

Each note separates three things:

  • What is known: supported by sources we can point to.
  • What looks promising: useful enough to watch or test, but not settled.
  • What is uncertain: claims that need better evidence or should stay out of strong recommendations.

Current questions

  • Which small practices are most useful in everyday life?
  • How can Brali show evidence without making the library hard to read?
  • How can an AI agent recommend a protocol without overstating confidence?
  • How should one protocol stay consistent across several languages?
  • Which old habit-tracking ideas are worth keeping as general knowledge?

From research to the library

A research note does not automatically become a trusted protocol. It can improve an existing protocol, add a source, change an evidence state, or create a new item for review.
