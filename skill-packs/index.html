One source, many reusable surfaces

Skills are generated, not rewritten by hand.

Brali packages only protocols that currently meet the public trust gate. A skill keeps the canonical protocol ID, URL, evidence state, action, check-in and guardrails attached.

  • Only reviewed and eligible practical records become public skills.
  • Pending-review and restricted records stay outside the executable catalog.
  • Every skill gets a stable crawlable URL instead of existing only inside a JavaScript picker.

A skill is a reuse and discovery surface, not a ranking shortcut or evidence that a search engine or AI system will recommend Brali.

Two ways to reuse Brali

For one bounded protocol, open its stable page and copy or save the generated SKILL.md. For broader retrieval, install the brali-life-os router skill above. For application integration, use the integration guides or the read-only API.

Why this exists

Many useful routines disappear inside long articles or lose their limitations when copied into prompts. Brali Agent Skills keep the action small, give each reusable unit a stable address, and keep provenance visible. If evidence state changes later, the canonical Brali protocol remains the record to re-check.
