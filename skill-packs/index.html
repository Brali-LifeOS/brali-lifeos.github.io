How to use a pack

Copy or save the generated SKILL.md and use it in an AI tool or agent workflow that accepts reusable instructions. Tool-specific installation differs, so Brali does not pretend one button installs everywhere. For direct data integration, use the integration guides or the read-only API.

Why this exists

Many useful routines disappear inside long articles or get stripped of their limitations when copied into AI prompts. Brali Skill Packs keep the action small and the provenance visible. If a protocol later changes evidence state, the canonical Brali record remains the source to re-check.
