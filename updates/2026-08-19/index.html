Brali this week: knowledge quality, query access, and agent adoption

Brali moved beyond a large hack archive toward a smaller trusted core, problem-first topic entry points, reproducible agent evaluation, and easier zero-install access.

Flagship 100 trusted core

A deterministic quality and safety policy now selects a 100-protocol trusted core instead of treating every inherited hack as equally ready for recommendation.

Source / related page →

Seven problem-first Topic Hubs

Sleep, Focus, Memory, Stress, Habits, Learning, and Movement now combine trusted protocols, evidence boundaries, and research-watch items in compact entry points.

Source / related page →

50-case agent evaluation suite

Brali added reproducible practical scenarios and later aligned the browser Query Playground with the same contract, reaching 50/50 maintained cases in the reported CI run.

Source / related page →

Zero-install Query Playground

A browser-only surface now lets people test Brali retrieval, inspect trust and provenance, and create shareable question URLs without installing an SDK or MCP client.

Source / related page →

Reference agents and MCP distribution work

Runnable reference-agent examples were published and the read-only Brali Knowledge MCP package was prepared for npm and MCP Registry distribution, with publication claims deliberately withheld until external publication is verified.

Source / related page →

Research became a correction loop

Recent work narrowed claims around retrieval practice, sleep regularity, movement breaks, and habit formation instead of using research as decorative citations.

Source / related page →

Next

  • Turn natural-language questions into stronger internal navigation without generating one page per keyword variation.
  • Keep replacing inherited unsupported claims with reviewed or clearly practical protocol content.
  • Track search performance only when first-party Search Console data is available; do not invent search-volume or ranking trends.

Why publish this?

Brali is changing quickly. A dated report makes additions, corrections, and platform work discoverable without pretending every code change deserves a standalone article.
